# Dogfood checklist (2 weeks)

Use this after loading `apps/ask-grok/dist` and `apps/vocab-builder/dist`.

## Week 1

- [ ] Save 5+ words from real reading (context menu).
- [ ] Add English definitions for saved words (Word list → Edit def).
- [ ] Complete at least 3 review sessions (due queue → 0).
- [ ] Use Ask Grok for 3+ in-page questions (selection or popup).

## Week 2

- [ ] Save 10+ total words with snippet + definition.
- [ ] Review most days; check stats (New → Learning → mature).
- [ ] Try **Save to Vocab Builder** from Ask Grok (after `link-extensions`).
- [ ] Note: definitions trustworthy enough to grade honestly?

## Stop / archive if

- You do not open either extension for 2 weeks, or
- You prefer Readlang/Anki/Grok tab only.

Otherwise consider polish only (no new features).
