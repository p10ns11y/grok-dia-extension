Based on our discussions, here's a detailed plan for extending the Grok Dia extension with an innovative vocabulary-building feature:

## Feature Overview
Users visit pages, extension extracts and ranks "unusual" words (rare nouns/verbs/adjectives) using TB-IDF, frequency analysis, and POS tagging. Stores words with multi-lingual meanings (English + 9 languages), relations to synonyms/antonyms, and context examples. Displays in an interactive D3.js graph with closeness indicating similarity. Includes search, daily learning games, and integration with existing Grok chat.

## Tech Stack (Simple & Browser-Native)
- **Extraction & Processing**: compromise.js for POS (~20KB), Lunr.js for search (~10KB)
- **Visualization**: D3.js for interactive graph (~100KB)
- **Storage**: Dexie.js wrapper over IndexedDB for relational data
- **Languages**: Pre-loaded corpora for English (WordNet subset), translations via free APIs or static data (e.g., from CC-licensed sources)
- **UI**: Extend popup with new sections/tabs, add separate extension pages for detailed views, integrate context menu 'Add to Vocab'

## Architecture
- **Background Script**: Handles extraction on page visits (content scripts), manages IndexedDB with Dexie
- **Popup**: 'Extract Vocab' button, quick list/graph view, link to separate vocab page
- **Vocab Page**: Full search, graph visualization, game modes (flashcards, matching)
- **Content Scripts**: Extract text when user clicks context menu
- **Options Page**: Preferences (languages to load, game settings)

## Data Models
- **Words Table**: {id, text, pos, freq_rank, dates_encountered}
- **Translations Table**: {word_id, lang, meaning, example_sentences}
- **Relations Table**: {word_id, related_id, type (synonym/antonym), similarity_percentage}
- **Corpus**: Pre-loaded JSON for common words/TFIDF baselines (~200KB total)

## Implementation Steps
1. Add vocab-related permissions/declarations in manifest.json
2. Create Dexie schema with tables and indexes
3. Implement text extraction in content script using compromise.js
4. Build word ranking algorithm (TF-IDF + frequency + POS)
5. Add translation fetching (start with static, later integrate Datamuse/Glosbe APIs)
6. Create D3.js graph component (force-directed with links for relations)
7. Extend popup.html/js with vocab tabs/sections
8. Add new vocab.html vocab.js files for dedicated learning page
9. Implement context menu for adding words manually
10. Add gamification (daily challenges, progress tracking)

## Potential Innovations & Efficiency
- **Graph**: Algorithm for force-directed layout where forces pull synonyms closer, antonyms further
- **Storage**: B-tree style indexing in IndexedDB for fast searches, compression for translations
- **Learning**: Spaced repetition with exponential backoff for review scheduling
- **Games**: Vocab bingo, synonym chains, antonym matching
- **Privacy**: All processing local, no data sent out
